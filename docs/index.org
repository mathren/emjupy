Emjupy is a package to run Jupyter notebooks in emacs aiming at
retaining the native emacs editing experience and the convenience of
notebooks for data exploration.

By design, it works with remote kernels using emacs built-ins (=eglot=
and =tramp=, completion framework the way you like and configured, e.g.,
=vertico= + =corfu= + =orderless=) while maintaining compatibility with
standard =*.ipynb= for sharing with non-emacs users.
